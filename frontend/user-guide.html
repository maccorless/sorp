How SARP Works

Simple guide to authentication and access

1 What is SARP?

SARP (Son of Access Request Portal) is a Single Sign-On system that lets you access multiple applications with one login. Once you sign in, you can access all authorized applications without logging in again.

Available Applications: MediaZone, Transportation, Wifi, Remote CIS, Weather, and SEAT

2 How to Sign In

You can sign in using one of two methods:

  • Accreditation Number: Use your 8-digit registration number and 4-digit CVV code. This gives you access to all applications you're authorized for.
  • Third-Party Token: Use a 16-digit token (format: ####-####-####-####). Each token is specific to one application.

3 Device Sessions

When you sign in, SARP remembers your browser for 90 days. You won't need to sign in again during this time when using the same browser.

How it works:
  • Each browser gets its own session
  • Sessions last 90 days from login
  • Multiple tabs in the same browser share the same session
  • Different browsers need separate logins

4 Device Limits

To prevent unauthorized sharing, there are limits on how many browsers/devices you can use:

  • Standard: Up to 3 devices per accreditation or token
  • Multiple Devices: Add an email or phone number for unlimited device access

If you reach your device limit, you'll need to logout from an active session before adding a new device.

5 Adding Email/Phone for Easy Access

You can link up to 2 email addresses and 2 phone numbers to your account. This allows:

  • Unlimited device access (no 3-device limit)
  • Login using email/phone with a one-time code
  • Easier access from multiple locations

6 Multiple Applications

With Accreditation: Your first login grants access to all applications you're authorized for. Switch between apps freely without re-authenticating.

With Token: Each token is specific to one application. You'll need different tokens for different apps.

Note for IT Administrators: Kiosk/Workstation Mode is available for shared devices in organizational settings. This feature is managed by IT administrators and allows multiple users on shared workstations.
